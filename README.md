# Natarinko Knowledge Base

> Building a trusted multilingual knowledge platform.

## About

Natarinko Knowledge Base is a long-term educational project aimed at creating a structured, evidence-based, multilingual encyclopedia covering science, history, technology, culture, society, and many other fields of knowledge.

The project is designed with the following principles:

- accuracy before speed;
- evidence before opinion;
- neutrality and clarity;
- long-term educational value;
- multilingual accessibility.

## Repository Structure

This repository contains:

- project documentation;
- editorial standards;
- article templates;
- taxonomy and classification;
- encyclopedia articles;
- supporting resources.
