# Contributing to Natarinko

Thank you for your interest in contributing.

## Principles

Contributors should:

- write objectively;
- use reliable sources;
- follow the editorial policy;
- follow the style guide;
- respect other contributors.

---

## Before Submitting

Please verify:

- factual accuracy;
- spelling and grammar;
- logical structure;
- references where needed.

---

## Goal

Every contribution should improve the educational value of the project.
